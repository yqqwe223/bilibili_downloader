📥 Detaillierte Anleitung (in nur 3 Schritten!)

Schritt 1: Holen Sie sich den Bilibili-Video-Link

  1. Öffnen Sie die offizielle Bilibili-Website
  2. Starten Sie das Video, das Sie herunterladen möchten
  3. Kopieren Sie den vollständigen Link (URL) aus der Adressleiste Ihres Browsers:
    https://www.bilibili.com/video/BV1Xx411c7mU
    oder https://www.bilibili.com/video/av12345678

💡 Tipp: Wenn das Video mehrere Teile hat (z. B. eine Tutorial-Reihe), stellen Sie sicher, dass der Link einen Parameter wie ?p=2 enthält, z. B.:
https://www.bilibili.com/video/BV1xx411c7mu?p=3
So laden Sie genau Teil 3 herunter.

Schritt 2: Link einfügen und analysieren

  1. Kehren Sie zu dieser Downloader-Seite zurück
  2. Fügen Sie den kopierten Bilibili-Link in das obere Eingabefeld ein
  3. Klicken Sie auf die Schaltfläche 【Video analysieren】

⏳ Warten Sie 1–5 Sekunden. Das System analysiert automatisch Titel, Uploader („UP“), Dauer und verfügbare Auflösungen des Videos.

Schritt 3: Format auswählen und herunterladen

Nach erfolgreicher Analyse werden folgende Optionen angezeigt:

  • 📹 Video-Downloadbereich: 1080p / 720p / 480p / 360p (MP4, Audio und Video bereits zusammengeführt)
  • 🔊 Audio-Downloadbereich: Nur Audio (AAC) oder in MP3 konvertiert
  • 💬 Danmaku- und Untertitelbereich: Danmaku (.xml) oder Untertitel (.srt) herunterladen

📌 Empfehlungen zur Nutzung:

  • Möchten Sie das vollständige Videoerlebnis speichern? → Laden Sie 1080p-Video + danmaku.xml herunter
  • Brauchen Sie nur den Ton? → Laden Sie MP3-Audio herunter
  • Benötigen Sie Material für die Videobearbeitung? → Wählen Sie das MP4 mit der höchsten verfügbaren Auflösung

Klicken Sie auf die entsprechende Schaltfläche – Ihr Browser startet automatisch den Download der Datei (normalerweise im Ordner „Downloads“ gespeichert).

❓ Häufig gestellte Fragen (FAQ)

F1: Warum passiert nichts, wenn ich auf „Herunterladen“ klicke?
A: Bitte prüfen Sie Folgendes:
- Blockiert Ihr Browser Pop-ups? → Erlauben Sie Pop-ups von dieser Website
- Verwenden Sie einen Werbeblocker (z. B. uBlock)? → Deaktivieren Sie ihn vorübergehend und versuchen Sie es erneut
- Ist Ihre Internetverbindung stabil? → Wechseln Sie das Netzwerk oder versuchen Sie es später erneut
F2: Das heruntergeladene MP4 ruckelt oder zeigt Bildstörungen?

A: Nein. Premium-Inhalte sind durch Bilibilis DRM geschützt, und dieses Tool kann diese Schutzmaßnahme nicht umgehen.
F4: Kann ich eine ganze Favoritenliste oder Wiedergabeliste herunterladen?
A: Die aktuelle Version unterstützt nur Einzelvideos oder einzelne Teile. Die Funktion für Massen-Downloads befindet sich in Entwicklung – bleiben Sie auf dem Laufenden!
F5: Funktioniert das Tool auf Mobilgeräten?
A: Absolut! Vollständig kompatibel mit iOS und Android. Nach dem Download finden Sie die Dateien in der „Dateien“-App (iOS) oder im „Download-Manager“ (Android).
