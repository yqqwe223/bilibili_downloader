## 📋 نظرة عامة على المشروع

هذا المشروع هو أداة تحليل فيديو قائمة على الويب، مُصممة لاستخراج بيانات وصفية لموارد الوسائط من الفيديوهات العامة على منصة Bilibili (哔哩哔哩) بطريقة آمنة، مع توفير خيارات للتحويل بين التنسيقات والحفظ المحلي. لا يتطلب تثبيت برامج عميل إضافية ولا تسجيل حساب: استخدمه مباشرة من خلال متصفحك.

> ⚠️ **تنبيه هام**: صُممت هذه الأداة حصرياً لأغراض التعلم الشخصي، والبحث التقني، والاستخدام ضمن حدود معقولة. يُرجى الالتزام بـ [اتفاقية مجتمع Bilibili](https://www.bilibili.com/blackboard/protocol.html) و《قانون حقوق النشر لجمهورية الصين الشعبية》واللوائح الأخرى السارية. احترم جهود المبدعين؛ لا تستخدم المحتوى الذي تم تنزيله لأغراض تجارية أو لانتهاك حقوق الآخرين.

## ✨ الميزات الرئيسية

- 🔗 **تحليل الروابط**: دعم روابط فيديو/أنمي Bilibili القياسية؛ الكشف التلقائي عن الحلقات وخيارات الدقة المتاحة
- 📥 **تصدير بتنسيقات متعددة**:
  - بث الفيديو الأصلي (يدعم الدقات العامة مثل 1080P/720P، إلخ)
  - استخراج الصوت → تنسيق MP3 (ملائم للاستماع للمحاضرات/الموسيقى دون اتصال)
  - مقطع فيديو → تحويل إلى صورة متحركة GIF (مثالي لإنشاء الميمز/العروض التعليمية)
- 🌍 **واجهة متعددة اللغات**: دعم اللغة العربية والإنجليزية والصينية واليابانية والكورية والمزيد
- 📱 **توافق متعدد المنصات**: يعمل بسلاسة على متصفحات Chrome / Firefox / Safari / Edge؛ تجربة مُحسّنة للأجهزة المحمولة والألواح اللوحية
- 🔒 **الخصوصية أولاً**: لا حاجة لتسجيل حساب Bilibili، لا يتم جمع بيانات شخصية؛ عملية التحليل مجهولة الهوية بالكامل
- ⚡ **معالجة سريعة**: يكتمل التحليل في متوسط 5-10 ثوانٍ؛ دعم للطلبات المتزامنة والمعالجة الدفعية

## 🚀 البدء السريع

### الاستخدام عبر الإنترنت (موصى به)
1. انتقل إلى [https://twittervideodownloaderx.com/bilibili_downloader_ar](https://twittervideodownloaderx.com/bilibili_downloader_ar)
2. انسخ رابط الفيديو المستهدف (مثال: `https://www.bilibili.com/video/BV1xx411c7mD`)
3. ألصق الرابط في حقل الإدخال → انقر على زر 「تحليل」
4. اختر الدقة والتنسيق المطلوبين → احفظ الملف باتباع إرشادات المتصفح

### النشر المحلي (للمطورين)
```bash
# استنساخ المستودع
git clone https://github.com/your-repo/bili-video-parser.git

# تثبيت التبعيات
cd bili-video-parser && npm install

# تهيئة متغيرات البيئة (اختياري)
cp .env.example .env

# تشغيل خادم التطوير
npm run dev
```

> 💡 ملاحظة: يستخدم هذا المشروع بنية قائمة على Node.js + Express. راجع وثائق النشر التفصيلية في `/docs/DEPLOY.md`

## 📚 دليل الاستخدام

### سير العمل الأساسي
```
1. الحصول على رابط الفيديو
   └─ افتح الفيديو المستهدف على Bilibili → انسخ عنوان URL من شريط عناوين المتصفح

2. إرسال طلب التحليل
   └─ ألصق الرابط في حقل إدخال الأداة → انقر على 「بدء التحليل」

3. اختيار تكوين الإخراج
   ├─ 🎬 تنزيل الفيديو: اختر الدقة (360P/720P/1080P، إلخ - خيارات عامة فقط)
   ├─ 🎵 استخراج الصوت: إنشاء ملف MP3 (مثالي للاستماع للمحاضرات/الموسيقى دون اتصال)
   └─ 🎞 إنشاء GIF: توليد رسوم متحركة من نطاق زمني محدد (موصى به: ≤15 ثانية)

4. حفظ الملف
   └─ سيتم فتح المورد في علامة تبويب جديدة → نقرة بزر الماوس الأيمن/القائمة → 「حفظ باسم」
```

### نصائح للاستخدام على الأجهزة المحمولة
- نظام iOS (متصفح Safari): زر المشاركة → 「الحفظ في الملفات」
- نظام Android (متصفح Chrome): اضغط مطولاً على معاينة الفيديو → 「تنزيل الفيديو」
- في حالة التشغيل التلقائي للفيديو: انقر على `⋮` في الزاوية العلوية اليمنى من المشغل → اختر 「تنزيل」

**س: هل يمكنني تحليل المحتوى الحصري للأعضاء أو الذي يتطلب تسجيل الدخول؟**  
ج: لا. تعمل هذه الأداة فقط مع الفيديوهات المُعدة كعامة، وتحترم إعدادات الوصول للمحتوى الأصلي.

**س: هل تنخفض جودة الصورة/الصوت بعد التحويل؟**  
ج: تحافظ تنزيلات الفيديو على معدل البت الأصلي للدقة المحددة. يستخدم تنسيق MP3 ترميزاً قياسياً بمعدل 128 كيلوبت في الثانية. يُحسّن تنسيق GIF معدل الإطارات وفقاً للمدة لتحقيق التوازن بين حجم الملف وسلاسة التشغيل.

**س: هل يتم تخزين سجل التنزيلات أو ذاكرة التخزين المؤقت؟**  
ج: لا. يتم نقل جميع الموارد مباشرة إلى جهاز المستخدم عبر وكيل مؤقت؛ لا يخزن الخادم أي طلبات أو ملفات وسائط.

**س: ماذا أفعل إذا فشل التحليل؟**  
ج: يُرجى التحقق من: ① ما إذا كان الرابط يشير إلى فيديو عام صالح ② ما إذا كانت اتصالك بالإنترنت مستقراً ③ جرب استخدام متصفح آخر. إذا استمرت المشكلة، لا تتردد في الإبلاغ عنها عبر فتح قضية (Issue).
