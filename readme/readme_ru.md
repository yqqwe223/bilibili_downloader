## 📋 Обзор проекта

Этот проект представляет собой веб-инструмент для анализа видео, предназначенный для безопасного извлечения метаданных медиаресурсов из публичных видео на платформе Bilibili (哔哩哔哩) с возможностью конвертации форматов и локального сохранения. Не требует установки клиентского ПО или регистрации аккаунта — используйте напрямую через браузер.

> ⚠️ **Важное уведомление**: Данный инструмент предназначен исключительно для личного обучения, технических исследований и использования в разумных пределах. Пожалуйста, соблюдайте [Правила сообщества Bilibili](https://www.bilibili.com/blackboard/protocol.html), 《Закон об авторском праве Китайской Народной Республики》 и другие применимые нормативные акты. Уважайте труд создателей; не используйте загруженный контент в коммерческих целях или для нарушения прав третьих лиц.

## ✨ Основные функции

- 🔗 **Анализ ссылок**: Поддержка стандартных URL видео/анимации Bilibili; автоматическое распознавание эпизодов и доступных опций разрешения
- 📥 **Экспорт в нескольких форматах**:
  - Оригинальный видеопоток (поддерживает публичные разрешения, такие как 1080P/720P и др.)
  - Извлечение аудио → Формат MP3 (удобно для прослушивания лекций/музыки офлайн)
  - Видеофрагмент → Конвертация в анимированный GIF (идеально для создания мемов/учебных демонстраций)
- 🌍 **Многоязычный интерфейс**: Поддержка русского, английского, китайского, японского, корейского и других языков
- 📱 **Кроссплатформенная совместимость**: Полная поддержка Chrome / Firefox / Safari / Edge; оптимизированный опыт для мобильных устройств и планшетов
- 🔒 **Приоритет конфиденциальности**: Вход в аккаунт Bilibili не требуется, личные данные не собираются; процесс анализа полностью анонимен
- ⚡ **Высокая скорость обработки**: Анализ завершается в среднем за 5-10 секунд; поддержка параллельных запросов и пакетной обработки

## 📚 Руководство по использованию

### Базовый рабочий процесс
```
1. Получить ссылку на видео
   └─ Откройте целевое видео на Bilibili → Скопируйте URL из адресной строки браузера

2. Отправить запрос на анализ
   └─ Вставьте ссылку в поле ввода инструмента → Нажмите 「Начать анализ」

3. Выбрать конфигурацию вывода
   ├─ 🎬 Скачать видео: Выбрать разрешение (360P/720P/1080P и др. - только публичные опции)
   ├─ 🎵 Извлечь аудио: Создать файл MP3 (идеально для прослушивания лекций/музыки офлайн)
   └─ 🎞 Создать GIF: Сгенерировать анимацию из указанного временного диапазона (рекомендуется: ≤15 секунд)

4. Сохранить файл
   └─ Ресурс откроется в новой вкладке → Правый клик/меню → 「Сохранить как」
```

### Советы для использования на мобильных устройствах
- iOS Safari: Кнопка «Поделиться» → 「Сохранить в Файлы」
- Android Chrome: Долгое нажатие на превью видео → 「Скачать видео」
- Если видео воспроизводится автоматически: Нажмите `⋮` в правом верхнем углу плеера → Выберите 「Скачать」

## ❓ Часто задаваемые вопросы

**В: Где сохраняются загруженные файлы?**  
О: Файлы сохраняются в папку загрузок, настроенную в вашем браузере. Вы можете проверить или изменить этот путь в настройках браузера.

**В: Можно ли анализировать контент только для участников или требующий входа в систему?**  
О: Нет. Этот инструмент работает только с видео, настроенными как публичные, и уважает настройки доступа к исходному контенту.

**В: Снижается ли качество изображения/звука после конвертации?**  
О: Загрузки видео сохраняют исходный битрейт выбранного разрешения. Формат MP3 использует стандартное кодирование 128 кбит/с. Формат GIF оптимизирует частоту кадров в зависимости от длительности для баланса между размером файла и плавностью.

**В: Сохраняется ли история загрузок или кэш?**  
О: Нет. Все ресурсы передаются непосредственно на устройство пользователя через временный прокси; сервер не хранит никакие запросы или медиафайлы.

**В: Что делать, если анализ не удался?**  
О: Пожалуйста, проверьте: ① Соответствует ли ссылка действительному публичному видео ② Стабильно ли ваше интернет-соединение ③ Попробуйте использовать другой браузер. Если проблема сохраняется, не стесняйтесь сообщить об этом через Issue.
