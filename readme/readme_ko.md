## 📋 프로젝트 개요

본 프로젝트는 빌리빌리 (Bilibili) 의 공개 동영상에서 미디어 리소스 메타데이터를 안전하게 추출하고, 다양한 형식으로 변환 및 로컬 저장을 지원하는 웹 기반 분석 도구입니다. 별도 클라이언트 설치나 계정 등록 없이, 브라우저에서 즉시 이용하실 수 있습니다.

> ⚠️ **중요 안내**: 본 도구는 개인 학습, 기술 연구, 합리적인 이용 범위 내에서만 사용하시기 바랍니다. [빌리빌리 커뮤니티 약관](https://www.bilibili.com/blackboard/protocol.html) 및 《중화인민공화국 저작권법》등 관련 법규를 준수하여, 창작자의 노동 성과를 존중하고 다운로드 콘텐츠를 상업적 목적이나 타인의 권리 침해 용도로 사용하는 것은 엄격히 금지됩니다.

## ✨ 주요 기능

- 🔗 **링크 분석**: 표준 빌리빌리 동영상/애니메이션 링크 지원, 에피소드 및 화질 옵션 자동 식별
- 📥 **다양한 내보내기 형식**:
  - 원본 동영상 스트림 (1080P/720P 등 공개 화질 지원)
  - 오디오 추출 → MP3 형식 (강의/음악 오프라인 청취에 편리)
  - 동영상 클립 → GIF 애니메이션 변환 (이모티콘 제작/교육 시연에 적합)
- 🌍 **다국어 인터페이스**: 한국어, 영어, 중국어, 일본어 등 다국어 지원
- 📱 **크로스 플랫폼 호환**: Chrome / Firefox / Safari / Edge 대응, 스마트폰·태블릿에서도 쾌적한 사용 경험
- 🔒 **프라이버시 우선**: B stand 계정 로그인 불필요, 사용자 정보 수집 없음, 분석 프로세스 완전 익명화
- ⚡ **고속 처리**: 평균 5-10 초 이내 분석 완료, 병렬 요청 및 배치 처리 지원

## 🚀 빠른 시작

### 온라인 이용 (권장)
1. [https://twittervideodownloaderx.com/bilibili_downloader_ko](https://twittervideodownloaderx.com/bilibili_downloader_ko) 에 접속
2. 대상 동영상 링크 복사 (예: `https://www.bilibili.com/video/BV1xx411c7mD`)
3. 입력창에 붙여넣기 → 「분석」버튼 클릭
4. 원하는 화질과 형식 선택 → 브라우저 안내에 따라 파일 저장

### 로컬 개발자용 배포
```bash
# 저장소 클론
git clone https://github.com/your-repo/bili-video-parser.git

# 종속성 설치
cd bili-video-parser && npm install

# 환경 변수 설정 (선택사항)
cp .env.example .env

# 개발 서버 실행
npm run dev
```

> 💡 참고: 본 프로젝트는 Node.js + Express 아키텍처를 기반으로 합니다. 상세 배포 절차는 `/docs/DEPLOY.md` 를 참조해 주세요.

## 📚 사용 가이드

### 기본 조작 흐름
```
1. 동영상 링크 취득
   └─ B stand 에서 대상 동영상 열기 → 브라우저 주소창에서 URL 복사

2. 분석 요청 전송
   └─ 도구 입력창에 링크 붙여넣기 → 「분석 시작」클릭

3. 출력 설정 선택
   ├─ 🎬 동영상 다운로드: 화질 선택 (360P/720P/1080P 등 공개 옵션)
   ├─ 🎵 오디오 추출: MP3 파일 생성 (강의/음악 오프라인 청취용)
   └─ 🎞 GIF 생성: 지정 시간 범위에서 애니메이션 생성 (권장: ≤15 초)

4. 파일 저장
   └─ 새 탭에서 리소스 열림 → 우클릭/메뉴 → 「다른 이름으로 저장」
```

### 스마트폰 이용 팁
- iOS Safari: 공유 버튼 → 「파일에 저장」
- Android Chrome: 동영상 미리보기 길게 누르기 → 「동영상 다운로드」
- 자동 재생 시: 플레이어 우측 상단 `⋮` → 「다운로드」선택

## ❓ 자주 묻는 질문

**Q: 다운로드한 파일은 어디에 저장되나요?**  
A: 브라우저 설정에 지정된 다운로드 폴더에 저장됩니다. 브라우저 설정 화면에서 저장 경로를 확인하거나 변경할 수 있습니다.

**Q: 회원 전용 또는 로그인 필요 콘텐츠도 분석할 수 있나요?**  
A: 아니요. 본 도구는 공개 설정된 동영상만 지원하며, 원본 콘텐츠의 접근 권한 설정을 존중합니다.

**Q: 변환 후 화질/음질이 저하되나요?**  
A: 동영상 다운로드는 선택한 화질의 원본 비트레이트를 유지합니다. MP3 는 128kbps 표준 인코딩, GIF 는 재생 시간에 따라 프레임 레이트를 최적화하여 파일 크기와 부드러움의 균형을 맞춥니다.

**Q: 다운로드 이력이나 캐시가 저장되나요?**  
A: 저장되지 않습니다. 모든 리소스는 임시 프록시 경유로 직접 사용자 기기로 전송되며, 서버 측에서는 요청 내용이나 미디어 파일을 일절 보관하지 않습니다.

**Q: 분석에 실패한 경우 어떻게 해야 하나요?**  
A: ① 유효한 공개 동영상 링크인지 확인 ② 네트워크 환경 안정성 확인 ③ 브라우저를 변경하여 재시도 해 주세요. 문제가 지속될 경우, Issue 를 통해 자유롭게 보고해 주시기 바랍니다.
