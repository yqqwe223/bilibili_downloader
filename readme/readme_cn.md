## 📋 项目简介

本项目是一个基于 Web 的哔哩哔哩（Bilibili）视频内容解析工具，支持从公开视频中提取媒体资源元数据，并提供多种格式的转换与本地保存选项。工具采用纯前端解析 + 后端代理的技术方案，无需安装客户端软件，开箱即用。

> ⚠️ **重要声明**：本工具仅用于个人学习、技术研究及合理使用场景。请遵守 [哔哩哔哩社区公约](https://www.bilibili.com/blackboard/protocol.html) 及《中华人民共和国著作权法》等相关法规，尊重创作者劳动成果，勿将下载内容用于商业用途或侵犯他人权益。

## ✨ 核心功能

- 🔗 **链接解析**：支持标准 Bilibili 视频/番剧链接，自动识别视频分集与清晰度选项
- 📥 **多格式导出**：
  - 原始视频流（支持 1080P/720P 等公开清晰度）
  - 音频提取 → MP3 格式（便于离线收听课程/音乐）
  - 视频片段 → GIF 动图转换（适合制作表情包/教学演示）
- 🌍 **多语言支持**：内置中/英/日等语言界面，方便不同地区用户使用
- 📱 **全平台兼容**：适配 Chrome / Firefox / Safari / Edge 等主流浏览器，支持移动端访问
- 🔒 **隐私保护**：无需登录 B 站账号，不收集用户个人信息，解析过程匿名化
- ⚡ **高效处理**：平均 5-10 秒内完成资源解析，支持并发请求与批量处理

## 🚀 快速开始

### 在线使用（推荐）
1. 访问 [https://twittervideodownloaderx.com/bilibili_downloader_cn](https://twittervideodownloaderx.com/bilibili_downloader_cn)

cd bili-video-parser && npm install

cp .env.example .env

## 📚 使用指南

### 基础操作
```
1. 获取视频链接
   └─ 在 B 站打开目标视频 → 复制浏览器地址栏 URL

2. 提交解析
   └─ 粘贴链接至工具输入框 → 点击「开始解析」

3. 选择输出配置
   ├─ 🎬 下载视频：选择清晰度（360P/720P/1080P 等公开选项）
   ├─ 🎵 提取音频：生成 MP3 文件（适合课程/音乐离线收听）
   └─ 🎞 生成 GIF：截取指定时间段生成动图（建议≤15秒）

4. 保存文件
   └─ 浏览器新标签页打开资源 → 右键/菜单 →「另存为」
```

### 移动端提示
- iOS Safari：点击分享按钮 →「存储到文件」
- Android Chrome：长按视频预览 →「下载视频」
- 如遇自动播放：点击播放器右上角 `⋮` → 选择「下载」

## ❓ 常见问题

**Q：下载的文件保存在哪里？**  
A：默认保存至浏览器设定的下载目录，可在浏览器设置中查看或修改路径。

**Q：支持会员专享或需登录观看的内容吗？**  
A：不支持。本工具仅能解析公开可见的视频资源，需遵循原内容的访问权限设置。

**Q：转换后的画质/音质会损失吗？**  
A：视频下载为所选清晰度的原始码率；MP3 采用 128kbps 标准编码；GIF 会根据时长自动优化帧率，平衡体积与流畅度。

**Q：工具会缓存我的下载内容吗？**  
A：不会。所有资源均通过临时代理直传至您的设备，服务器不存储任何用户请求或媒体文件。

**Q：遇到解析失败怎么办？**  
A：请检查：① 链接是否为有效公开视频 ② 网络环境是否稳定 ③ 尝试更换浏览器。如问题持续，欢迎提交 Issue 反馈。
