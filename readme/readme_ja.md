## 📋 プロジェクト概要

本プロジェクトは、哔哩哔哩（Bilibili）の公開動画からメディアリソースのメタデータを安全に抽出し、複数形式への変換・ローカル保存をサポートする Web ベースの解析ツールです。クライアント不要・登録不要で、ブラウザからすぐに利用できます。

> ⚠️ **重要なお知らせ**：本ツールは個人学習・技術研究・合理的な利用範囲でのみご使用ください。[哔哩哔哩コミュニティ規約](https://www.bilibili.com/blackboard/protocol.html) 及び《中華人民共和国著作権法》等相关法規を遵守し、クリエイターの労働成果を尊重し、ダウンロード内容を商業目的や他者の権利侵害に使用することは固くお断りいたします。

---

## ✨ 主な機能

- 🔗 **リンク解析**：標準的な Bilibili 動画/アニメリンクに対応、エピソードと解像度オプションを自動識別
- 📥 **多形式エクスポート**：
  - オリジナル動画ストリーム（1080P/720P 等公開解像度をサポート）
  - 音声抽出 → MP3 形式（講座/音楽のオフライン視聴に便利）
  - 動画クリップ → GIF アニメーション変換（スタンプ作成/教学演示に最適）
- 🌍 **多言語インターフェース**：日本語・英語・中国語など複数言語をサポート
- 📱 **クロスプラットフォーム**：Chrome / Firefox / Safari / Edge 対応、スマートフォン・タブレットでも快適操作
- 🔒 **プライバシー重視**：B 站アカウントログイン不要、ユーザー情報収集なし、解析プロセスは完全匿名
- ⚡ **高速処理**：平均 5-10 秒以内で解析完了、並列リクエスト・バッチ処理対応

## 📚 使い方ガイド

### 基本操作フロー
```
1. 動画リンクの取得
   └─ B 站上で対象動画を開く → ブラウザのアドレスバーから URL をコピー

2. 解析リクエストの送信
   └─ ツールの入力欄にリンクを貼り付け →「解析を開始」をクリック

3. 出力設定の選択
   ├─ 🎬 動画ダウンロード：解像度を選択（360P/720P/1080P 等公開オプション）
   ├─ 🎵 音声抽出：MP3 ファイルを生成（講座/音楽のオフライン視聴に最適）
   └─ 🎞 GIF 生成：指定時間範囲でアニメーションを作成（推奨：≤15 秒）

4. ファイルの保存
   └─ 新規タブでリソースが開く → 右クリック/メニュー →「名前を付けて保存」
```

### スマートフォン利用時のヒント
- iOS Safari：共有ボタン →「ファイルに保存」
- Android Chrome：動画プレビューを長押し →「動画をダウンロード」
- 自動再生される場合：プレーヤー右上の `⋮` →「ダウンロード」を選択

## ❓ よくある質問

**Q：ダウンロードしたファイルはどこに保存されますか？**  
A：ブラウザの設定で指定されたダウンロードフォルダに保存されます。ブラウザの設定画面から保存先を確認・変更可能です。

**Q：会員限定またはログインが必要なコンテンツも解析できますか？**  
A：いいえ。本ツールは公開設定の動画のみ対応しており、元のコンテンツのアクセス権限設定を尊重します。

**Q：変換後の画質・音質は劣化しますか？**  
A：動画ダウンロードは選択した解像度のオリジナルビットレートを維持します。MP3 は 128kbps の標準エンコード、GIF は再生時間に応じてフレームレートを最適化し、ファイルサイズと滑らかさのバランスを取ります。

**Q：ダウンロード履歴やキャッシュは保存されますか？**  
A：保存されません。すべてのリソースは一時プロキシ経由で直接ユーザー端末へ転送され、サーバー側ではリクエスト内容やメディアファイルは一切保持しません。

**Q：解析に失敗した場合はどうすればいいですか？**  
A：請检查：① 有効な公開動画リンクか確認 ② ネットワーク環境の安定性を確認 ③ ブラウザを変更して再試行 してください。問題が解決しない場合は、Issue よりお気軽にご報告ください。
