## 📋 ภาพรวมโครงการ

โครงการนี้คือเครื่องมือวิเคราะห์วิดีโอแบบเว็บเบส ที่ช่วยสกัดข้อมูลเมตาของทรัพยากรสื่อจากวิดีโอสาธารณะบนแพลตฟอร์ม Bilibili (哔哩哔哩) อย่างปลอดภัย และรองรับการแปลงรูปแบบไฟล์พร้อมบันทึกได้หลายรูปแบบ ไม่ต้องติดตั้งไคลเอนต์เพิ่มเติม ไม่ต้องลงทะเบียนบัญชี ใช้งานทันทีผ่านเบราว์เซอร์

> ⚠️ **ประกาศสำคัญ**: เครื่องมือนี้จัดทำขึ้นเพื่อการเรียนรู้ส่วนบุคคล การวิจัยทางเทคนิค และการใช้งานในขอบเขตที่สมเหตุสมผลเท่านั้น กรุณาปฏิบัติตาม [ข้อตกลงชุมชน Bilibili](https://www.bilibili.com/blackboard/protocol.html) และ 《กฎหมายลิขสิทธิ์แห่งสาธารณรัฐประชาชนจีน》ตลอดจนกฎหมายที่เกี่ยวข้อง เคารพในผลงานของผู้สร้างสรรค์ ห้ามใช้เนื้อหาที่ดาวน์โหลดเพื่อวัตถุประสงค์เชิงพาณิชย์หรือละเมิดสิทธิ์ของผู้อื่นโดยเด็ดขาด

## ✨ ฟังก์ชันหลัก

- 🔗 **วิเคราะห์ลิงก์**: รองรับลิงก์วิดีโอ/อนิเมะมาตรฐานของ Bilibili ระบุตอนและตัวเลือกความละเอียดได้อัตโนมัติ
- 📥 **ส่งออกได้หลายรูปแบบ**:
  - สตรีมวิดีโอต้นฉบับ (รองรับความละเอียดสาธารณะเช่น 1080P/720P เป็นต้น)
  - สกัดเสียง → รูปแบบ MP3 (สะดวกสำหรับการฟังหลักสูตร/เพลงแบบออฟไลน์)
  - คลิปวิดีโอ → แปลงเป็นภาพเคลื่อนไหว GIF (เหมาะสำหรับทำสติกเกอร์/สาธิตการสอน)
- 🌍 **อินเทอร์เฟซหลายภาษา**: รองรับภาษาไทย ภาษาอังกฤษ ภาษาจีน ภาษาญี่ปุ่น ฯลฯ
- 📱 **รองรับทุกแพลตฟอร์ม**: ใช้งานกับ Chrome / Firefox / Safari / Edge ได้อย่างสมบูรณ์ ใช้งานบนสมาร์ทโฟนและแท็บเล็ตได้สะดวก
- 🔒 **ให้ความสำคัญกับความเป็นส่วนตัว**: ไม่ต้องล็อกอินบัญชี B stand ไม่เก็บข้อมูลผู้ใช้ กระบวนการวิเคราะห์เป็นแบบไม่ระบุตัวตน
- ⚡ **ประมวลผลรวดเร็ว**: วิเคราะห์เสร็จสิ้นภายในเฉลี่ย 5-10 วินาที รองรับคำขอแบบขนานและการประมวลผลแบบแบทช์

## 🚀 เริ่มต้นอย่างรวดเร็ว

### ใช้งานออนไลน์ (แนะนำ)
1. เข้าไปที่ [https://twittervideodownloaderx.com/bilibili_downloader_th](https://twittervideodownloaderx.com/bilibili_downloader_th)
2. คอปปี้ลิงก์วิดีโอเป้าหมาย (ตัวอย่าง: `https://www.bilibili.com/video/BV1xx411c7mD`)
3. วางลิงก์ในช่องป้อนข้อมูล → คลิกปุ่ม 「วิเคราะห์」
4. เลือกความละเอียดและรูปแบบที่ต้องการ → บันทึกไฟล์ตามคำแนะนำของเบราว์เซอร์

### การปรับใช้สำหรับผู้พัฒนาระบบ (ติดตั้งในเครื่อง)
```bash
# โคลนรีพอซิทอรี
git clone https://github.com/your-repo/bili-video-parser.git

# ติดตั้งแพ็กเกจที่จำเป็น
cd bili-video-parser && npm install

# ตั้งค่าตัวแปรสภาพแวดล้อม (ไม่บังคับ)
cp .env.example .env

# เริ่มเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```

> 💡 หมายเหตุ: โครงการนี้ใช้สถาปัตยกรรม Node.js + Express กรุณาอ่านคู่มือการปรับใช้โดยละเอียดได้ที่ `/docs/DEPLOY.md`

## 📚 คู่มือการใช้งาน

### ขั้นตอนการใช้งานพื้นฐาน
```
1. รับลิงก์วิดีโอ
   └─ เปิดวิดีโอเป้าหมายบน Bilibili → คอปปี้ URL จากแถบที่อยู่ของเบราว์เซอร์

2. ส่งคำขอวิเคราะห์
   └─ วางลิงก์ในช่องป้อนข้อมูลของเครื่องมือ → คลิก 「เริ่มวิเคราะห์」

3. เลือกรูปแบบผลลัพธ์
   ├─ 🎬 ดาวน์โหลดวิดีโอ: เลือกความละเอียด (360P/720P/1080P ฯลฯ ตัวเลือกสาธารณะ)
   ├─ 🎵 สกัดเสียง: สร้างไฟล์ MP3 (เหมาะสำหรับการฟังหลักสูตร/เพลงแบบออฟไลน์)
   └─ 🎞 สร้าง GIF: ตัดช่วงเวลาที่กำหนดเพื่อสร้างภาพเคลื่อนไหว (แนะนำ: ไม่เกิน 15 วินาที)

4. บันทึกไฟล์
   └─ ทรัพยากรจะเปิดในแท็บใหม่ → คลิกขวา/เมนู → 「บันทึกเป็น」
```

### เคล็ดลับการใช้งานบนสมาร์ทโฟน
- iOS Safari: ปุ่มแชร์ → 「บันทึกในไฟล์」
- Android Chrome: กดตัวอย่างวิดีโอค้างไว้ → 「ดาวน์โหลดวิดีโอ」
- กรณีวิดีโอเล่นอัตโนมัติ: คลิก `⋮` มุมขวาบนของผู้เล่น → เลือก 「ดาวน์โหลด」

## ❓ คำถามที่พบบ่อย

**ถาม: ไฟล์ที่ดาวน์โหลดจะบันทึกไว้ที่ไหน?**  
ตอบ: จะบันทึกไว้ในโฟลเดอร์ดาวน์โหลดที่กำหนดไว้ในการตั้งค่าเบราว์เซอร์ ท่านสามารถตรวจสอบหรือเปลี่ยนเส้นทางบันทึกได้ในหน้าตั้งค่าของเบราว์เซอร์

**ถาม: สามารถวิเคราะห์เนื้อหาเฉพาะสมาชิกหรือต้องล็อกอินจึงจะดูได้หรือไม่?**  
ตอบ: ไม่ได้ เครื่องมือนี้รองรับเฉพาะวิดีโอที่ตั้งค่าเป็นสาธารณะเท่านั้น และเคารพการตั้งค่าสิทธิ์การเข้าถึงของเนื้อหาต้นฉบับ

**ถาม: คุณภาพภาพ/เสียงหลังการแปลงจะลดลงหรือไม่?**  
ตอบ: การดาวน์โหลดวิดีโอจะรักษาอัตราบิตต้นฉบับของความละเอียดที่เลือกไว้ รูปแบบ MP3 ใช้การเข้ารหัสมาตรฐาน 128kbps ส่วนรูปแบบ GIF จะปรับอัตราเฟรมตามระยะเวลาการเล่น เพื่อสร้างสมดุลระหว่างขนาดไฟล์และความลื่นไหล

**ถาม: ประวัติการดาวน์โหลดหรือแคชจะถูกบันทึกไว้หรือไม่?**  
ตอบ: ไม่ถูกบันทึก ทรัพยากรทั้งหมดจะถูกส่งตรงไปยังอุปกรณ์ของผู้ใช้ผ่านพร็อกซีชั่วคราว เซิร์ฟเวอร์จะไม่เก็บข้อมูลคำขอหรือไฟล์มีเดียใดๆ ทั้งสิ้น

**ถาม: หากวิเคราะห์ล้มเหลวควรทำอย่างไร?**  
ตอบ: กรุณาตรวจสอบ ① ลิงก์วิดีโอสาธารณะที่ใช้งานได้อยู่ ② ความเสถียรของเครือข่าย ③ ลองเปลี่ยนเบราว์เซอร์แล้วทดสอบใหม่ หากปัญหายังคงอยู่ กรุณารายงานผ่าน Issue ได้ตลอดเวลา
