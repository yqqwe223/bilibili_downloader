🎬 B站動画ダウンローダー

高画質ダウンロード・音声と映像の分離・コメント（弾幕）エクスポート・無料オンライン利用

🔒 重要なお約束：当ツールはユーザーの動画リンクを一切保存せず、いかなる個人情報も収集しません。個人的かつ非営利目的でのみご利用ください。著作権を尊重し、クリエイターを応援しましょう！

🔍 このツールでできること

機能 説明
📹 複数解像度での動画ダウンロード 360P、480P、720P、1080P（一部動画は1080P+にも対応）をサポート。音声と映像を自動で統合し、標準MP4ファイルとして出力するため、すぐに再生可能です。
🎧 音声のみの抽出 高音質のAAC/MP3音声をワンクリックで抽出。ポッドキャスト、音楽、ナレーションなどを保存するのに最適です。
💬 コメント（弾幕）ファイルのエクスポート オリジナルのコメントデータを.xml形式でダウンロード可能。PotPlayerやVLCなどのプレーヤーにインポートして、オフラインでコメント付き再生が可能です。
🧩 字幕対応（テスト中） 動画に公式字幕が含まれている場合、.srt形式の字幕ファイルを同時にダウンロードできます（字幕機能が投稿者により有効化されている必要があります）。
🌐 全プラットフォーム対応 Windows / macOS / Linux / iOS / Android すべてに対応。主要ブラウザでご利用いただけます。
🚀 高速解析 最適化された解析アルゴリズムにより、動画情報の取得を平均3秒以内で完了します。

✅ 現在対応しているもの：一般の投稿動画（AV番号 / BV番号）、複数パート動画（複数回シリーズ）
❌ 現在対応していないもの：大会員限定コンテンツ、著作権保護されたアニメ・映画・ドラマ、ライブ配信のアーカイブなど、DRM保護されたコンテンツ

📥 詳細な使い方（たった3ステップ！）

ステップ1：B站の動画リンクを取得

  1. Bilibili公式サイトを開く
  2. ダウンロードしたい動画を再生する
  3. ブラウザのアドレスバーからURLをコピー
    https://www.bilibili.com/video/BV1Xx411c7mU
    または https://www.bilibili.com/video/av12345678

💡 小技：動画が複数パート（例：連載チュートリアル）の場合、URLに?p=2などのパラメータが含まれていることを確認してください。例：
https://www.bilibili.com/video/BV1xx411c7mu?p=3
これにより、第3話のコンテンツを正確にダウンロードできます。

ステップ2：リンクを貼り付けて解析

  1. このダウンローダーページに戻る
  2. 上部の入力欄にコピーしたB站のリンクを貼り付ける
  3. 【動画を解析】ボタンをクリック

⏳ 1〜5秒ほどお待ちください。動画のタイトル、投稿者（UP主）、再生時間、利用可能な画質などの情報が自動的に解析されます。

ステップ3：形式を選択してダウンロード

解析が成功すると、以下のオプションが表示されます：

  • 📹 動画ダウンロードエリア：1080P / 720P / 480P / 360P（MP4、音声と映像はすでに統合済み）
  • 🔊 音声ダウンロードエリア：音声のみ（AAC）またはMP3形式に変換
  • 💬 コメント・字幕エリア：コメント（.xml）または字幕（.srt）のダウンロード

📌 おすすめの使い方：

  • 動画の体験をそのまま保存したい場合 → 1080P動画＋コメント.xmlをダウンロード
  • 音声だけが必要な場合 → MP3音声をダウンロード
  • 動画編集用の素材が欲しい場合 → 最高画質のMP4を選択

該当ボタンをクリックすると、ブラウザが自動的にファイルのダウンロードを開始します（通常、「ダウンロード」フォルダに保存されます）。

⚙️ 技術的説明（開発者・上級ユーザー向け）

  • 音声・映像処理：B站の高画質動画の一部はDASH方式で配信されており（映像ストリームと音声ストリームが分離）、当ツールはバックエンドで自動的にこれらを統合し、単一のMP4ファイルとして出力します。
  • コメント（弾幕）の取得元：コメントデータはB站の公開APIから取得され、タイムスタンプやスタイル情報などの元データをそのまま保持しています。
  • プロキシなし・キャッシュなし：すべての動画ファイルはB站のCDNから直接ダウンロードされ、当サーバーはコンテンツを中継・保存しません。
  • オープンソースで監査可能：本プロジェクトのコアコードはGitHubで公開されており、レビュー・貢献を歓迎します。

❓ よくある質問（FAQ）

Q1：ダウンロードボタンを押しても反応がないのはなぜですか？
A：以下の点をご確認ください：
- ブラウザのポップアップブロック機能が有効になっていませんか？→ 当サイトのポップアップを許可してください
- 広告ブロッカー（例：uBlock）を使用していませんか？→ 一時的に無効化して試してみてください
- ネットワーク接続は安定していますか？→ 通信環境を変更するか、少し時間をおいて再試行してください
Q2：ダウンロードしたMP4が再生中にカクついたり、映像が乱れるのはなぜですか？
A：高ビットレートの動画は端末のデコード処理に負荷がかかる場合があります。720Pバージョンを試すか、VLCやPotPlayerなどの専門プレーヤーでの再生をおすすめします。
Q3：大会員限定動画はダウンロードできますか？
A：できません。大会員コンテンツはB站のDRM保護が適用されており、当ツールでは認証を回避できません。
Q4：お気に入りフォルダやプレイリスト全体をダウンロードできますか？
A：現バージョンでは単一動画または単一パートのみのダウンロードに対応しています。一括ダウンロード機能は現在開発中です。今後のアップデートにご期待ください！
Q5：スマートフォンでも使えますか？
A：はい、問題なくご利用いただけます！iOSおよびAndroidの両方で対応しています。ダウンロード後は、iOSの「ファイル」アプリやAndroidの「ダウンロードマネージャー」などでファイルを確認できます。
